# מאסה קליסטניקס — Massa Calisthenics

## 📱 מה זה?
אפליקציית ווב רספונסיבית לאימוני קליסטניקס — ממתחילים עד מקצוענים.
בנויה כקובץ HTML אחד (Single Page Application) — עובדת בכל דפדפן, גם על מובייל,
וגם ארוזה כאפליקציית iOS/Android אמיתית דרך Capacitor (ראו `app-store-prep.zip`).

## ✅ תכונות קיימות
- **5 רמות התקדמות** (מתחיל → מתקדם → בינוני → מתקדם+ → מקצוען)
- **30 תרגילים** עם מטרות, טיפים, וקישור לסרטון הדרכה אמיתי (YouTube, כל ה-30)
- **קוויז 20 שאלות** לקביעת רמה אישית + אפשרות "לא יודע"
- **ניתוח AI לביצוע** — Pose Detection אמיתי (TensorFlow.js / MoveNet) שרץ מקומית במכשיר על פריימים מהמצלמה
- **מצלמה + הקלטת וידאו** לניתוח בזמן אמת
- **תוכנית אימונים אישית** לשבוע עם בחירת ימים ושעות
- **דף פרופיל מלא** — שם, גיל, מין, ספורט נוסף, מטרה
- **היסטוריית אימונים** עם תאריכים וציונים — נשמר ב-localStorage, לא נמחק ברענון
- **מצב "המסע שלי"** — טיימליין של כל האירועים
- **מערכת הישגים** — 12 מדליות עם תנאי פתיחה
- **דף סרטוני הדרכה** — 30 תרגילים עם חיפוש
- **נגן סרטון** — מידע על התרגיל + כפתור "התחל תרגיל זה"
- **ניווט תחתון** — 5 לשוניות (בית, סרטונים, סטטיסטיקה, מסע, עוד)
- **עיצוב Dark/Light Mode** — טוגל אמיתי, נשמר לפי בחירה
- **4 שפות מלאות** — עברית (RTL), אנגלית, הולנדית, ספרדית
- **PWA אמיתי** — manifest.json, Service Worker (sw.js), אייקונים אמיתיים, עובד אופליין (למעט וידאו YouTube ו-API תזונה שדורשים רשת מטבעם)

## 🚀 איך להריץ
1. פתח את `index.html` בדפדפן (Chrome/Edge/Safari) — זהו הקובץ הפעיל היחיד, לא `masa_calisthenics.html` (גרסה ישנה/לא בשימוש שנשארה בהיסטוריה).
2. עובד גם דרך GitHub Pages (מוגדר כבר ב-`.github/workflows/pages.yml`) וגם דרך Vercel (`vercel.json`).
3. לבניית אפליקציית iOS/Android אמיתית: פתחו את `app-store-prep.zip` → `capacitor-app/` (מכיל פרויקט Xcode ו-Android Studio מוכן עם `npx cap sync`).

## 📁 מבנה הקובץ
- `index.html` — קובץ ה-SPA המלא: CSS, JS, וכל ה-data (תרגילים, שאלות, הישגים) inline.
- `manifest.json`, `sw.js`, `icons/` — תשתית PWA אמיתית.
- `vendor/` — Chart.js, גופן Heebo, ו-TensorFlow.js/MoveNet מקומיים (לא תלויים ב-CDN בזמן ריצה, כדי שהאפליקציה תעבוד גם אופליין).
- `app-store-prep.zip` — עטיפת Capacitor ל-iOS/Android + טקסטים ל-App Store Connect / Google Play Console.

## ⚠️ ידוע / מגבלות שנותרו
- נגישות (aria-labels) תוקנה בניווט הראשי בלבד — סקירת נגישות מלאה לכל הקובץ עוד לא בוצעה.
- אייקוני Android (mipmap בצפיפויות שונות) עדיין עם ברירת המחדל של Capacitor — רק אייקון ה-iOS עודכן למותג האמיתי.
- ניתוח ה-AI מבוסס Pose Detection גנרי (ספירת חזרות, טווח תנועה, יציבות) ולא ביומכניקה ספציפית לכל אחד מ-30 התרגילים.

## 🗣️ שפות
עברית (RTL), אנגלית, הולנדית, ספרדית — הכל עובד בפועל דרך מערכת i18n מלאה.

# מסע קליסטניקס — Calisthenics Journey v3.0

## 📱 מה זה?
אפליקציית ווב רספונסיבית לאימוני קליסטניקס — ממתחילים עד מקצוענים.
בנויה כקובץ HTML אחד (Single Page Application) — עובדת בכל דפדפן, גם על מובייל.

## ✅ תכונות (v3.0)

### 🏠 Core
- **5 רמות התקדמות** (מתחיל → מתקדם → בינוני → מתקדם+ → מקצוען)
- **30 תרגילים** עם מטרות, טיפים, וקישור לסרטון YouTube
- **קוויז 20 שאלות** לקביעת רמה אישית
- **AI מנתח ביצוע** (מדומה — ציון 1-100 עם פירוח)
- **מצלמה + הקלטת וידאו** לניתוח בזמן אמת
- **תוכנית אימונים אישית** לשבוע עם בחירת ימים ושעות

### 🌍 רב-לשוני
- **עברית (HE)** — RTL מלא
- **English (EN)**
- **Nederlands (NL)**
- **Español (ES)**

### 💾 שמירת נתונים
- **localStorage** — כל הנתונים נשמרים במכשיר
- פרופיל, התקדמות, היסטוריה, הישגים, המסע
- שפה, theme, הגדרות התראות

### 🎨 עיצוב
- **Dark/Light Mode** — החלפה בלחיצה
- **Bottom Nav** — לא עולה עם המקלדת
- **Loading Screen** — אנימציית טעינה
- **Particles** — אפקט רקע מונפש

### ⭐ XP System
- **נקודות ניסיון** לכל פעולה
- **10 רמות XP** עם פרסים
- בר התקדמות מונפש

### 📊 גרפים (Chart.js)
- אימונים לאורך זמן
- ציונים לאורך זמן
- פילוח שבועי
- משקל ואחוז שומן

### 📏 מדדים גופניים
- משקל, אחוז שומן
- היקפים: חזה, מותן, ידיים, ירכיים
- גרפי התקדמות

### 🥗 יומן תזונה
- לוג אוכל יומי
- קלוריות, חלבון, פחמימות, שומנים
- סיכומים יומיים

### 🔥 אתגר יומי
- תרגיל מיוחד כל יום
- בונוס XP
- טיימר ספירה לאחור

### ⏱️ מצב מירוץ
- אימון נגד השעון
- בחירת תרגיל ומטרה
- ציון לפי זמן

### 🔔 התראות
- תזכורות לפני אימון
- תזכורת אתגר יומי
- תזכורת לא לשבור רצף

### 📴 מצב Offline
- עבודה ללא אינטרנט
- סטטוס חיבור
- מידע על נתונים במטמון

## 🚀 איך להריץ
1. פתח את `masa_calisthenics.html` בדפדפן (Chrome/Edge/Safari)
2. או העלה ל-GitHub Pages:
   - צור repo חדש
   - העלה את הקובץ
   - Settings → Pages → בחר branch
   - יעלה ב-`username.github.io/repo-name`

## 📁 מבנה הקובץ
קובץ HTML אחד שמכיל:
- CSS מלא (inline) — עיצוב רספונסיבי
- JavaScript מלא (inline) — כל הלוגיקה
- Chart.js (CDN)
- כל ה-data — תרגילים, שאלות, הישגים, תרגומים

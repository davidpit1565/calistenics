# מסע קליסטניקס — Calisthenics Journey

## 📱 מה זה?
אפליקציית ווב רספונסיבית לאימוני קליסטניקס — ממתחילים עד מקצוענים.
בנויה כקובץ HTML אחד (Single Page Application) — עובדת בכל דפדפן, גם על מובייל.

## ✅ תכונות קיימות
- **5 רמות התקדמות** (מתחיל → מתקדם → בינוני → מתקדם+ → מקצוען)
- **30 תרגילים** עם מטרות, טיפים, וקישור לסרטון הדרכה
- **קוויז 20 שאלות** לקביעת רמה אישית + אפשרות "לא יודע"
- **AI מנתח ביצוע** (מדומה כרגע — ציון 1-100 עם פירוח)
- **מצלמה + הקלטת וידאו** לניתוח בזמן אמת
- **תוכנית אימונים אישית** לשבוע עם בחירת ימים ושעות
- **דף פרופיל מלא** — שם, גיל, מין, ספורט נוסף, מטרה
- **היסטוריית אימונים** עם תאריכים וציונים
- **מצב "המסע שלי"** — טיימליין של כל האירועים
- **מערכת הישגים** — 12 מדליות עם תנאי פתיחה
- **דף סרטוני הדרכה** — 30 תרגילים עם חיפוש
- **נגן סרטון** — מידע על התרגיל + כפתור "התחל תרגיל זה"
- **ניווט תחתון** — 5 לשוניות (בית, סרטונים, מסע, הישגים, פרופיל)
- **עיצוב Dark Mode מודרני** — צבעים, אנימציות, particles

## 🚀 איך להריץ
1. פתח את `masa_calisthenics.html` בדפדפן (Chrome/Edge/Safari)
2. או העלה ל-GitHub Pages:
   - צור repo חדש
   - העלה את הקובץ
   - Settings → Pages → בחר branch
   - יעלה ב-`username.github.io/repo-name`

## 📁 מבנה הקובץ
קובץ HTML אחד שמכיל:
- CSS מלא (inline) — עיצוב רספונסיבי
- JavaScript מלא (inline) — כל הלוגיקה
- כל ה-data — תרגילים, שאלות, הישגים

## ⚠️ ידוע / באגים
